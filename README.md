
# Kidney Disease Risk Prediction - MLOps

## Experiment 1: Synthetic Dataset Creation

### Objective
To generate synthetic kidney disease risk
data and implement dataset version management.

### Dataset Information

- Dataset V1: 1000 records
- Dataset V2: 1500 records
- Input Features: 12
- Target Column: Disease_Risk
- Classes: 5

### Dataset Versions

| Version | Changes |
|---------|---------|
| V1 | Initial 1000 records |
| V2 | Added 500 records and missing values |

### Tools Used
- Python
- Pandas
- NumPy
- Git and GitHub

### Version Management
SHA-256 checksums and JSON metadata
are used to track dataset versions
and verify dataset integrity.
